# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately** — do not open a public issue.
Email: security@mechat.example (replace with your real contact before release)
or use GitHub private vulnerability reporting.

Include: affected version, steps to reproduce, impact. We aim to acknowledge within
72 hours. Please do not publicly disclose until a fix is released.

## Scope

In scope: the Android app (`app/`) and the relay server (`server/`).
Out of scope: attacks requiring physical/forensic access to an unlocked device,
social engineering, and the security of third-party infrastructure you self-host.
